Veterinary Patient Calculator 🐾

A beginner Python project designed to practice programming fundamentals through a veterinary medicine example.

Project Goal

This project calculates and evaluates basic veterinary patient parameters such as:

- Age
- Weight
- Body temperature
- Heart rate
- Respiratory rate

Learning Objectives

This project is part of my learning path in:

- Python programming
- Problem solving
- Data handling
- Veterinary data analysis
- Git and GitHub

Background

I am a veterinarian and veterinary pathologist currently studying Computer Engineering.

This project is an early step toward combining veterinary medicine with computer science, data analysis, and artificial intelligence.
